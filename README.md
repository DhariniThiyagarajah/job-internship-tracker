# Job & Internship Application Tracker

A full-stack web application designed to help students and job seekers organise, manage, and track their job and internship applications in one place.

## Project Overview

Finding internships and jobs involves managing multiple applications, deadlines, interviews, and company details. This application aims to simplify that process by providing a centralised platform to manage the entire application journey.

## Objectives

- Manage job and internship applications.
- Track application statuses.
- Organise company and recruiter information.
- Record interview schedules and notes.
- Monitor upcoming deadlines.
- Analyse application progress through a dashboard.
